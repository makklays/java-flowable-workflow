
---- PATTERNS CATALOG ----

1 Порождающие (Creational)
Отвечают за создание объектов. Позволяют отделить процесс создания объектов от их использования, повысить гибкость и переиспользуемость.
Singleton        — только один экземпляр класса.
Factory Method   — создание объектов через метод, не указывая конкретный класс.
Abstract Factory — семейство связанных объектов без привязки к конкретным классам.
Builder          — пошаговое создание сложного объекта.
Prototype        — создание объекта через клонирование существующего.

2 Структурные (Structural)
Отвечают за структуру и композицию объектов, чтобы объекты можно было объединять, расширять или заменять без изменения кода.
🔧 Коротко с аналогиями:
Паттерн	    - Аналог в реальной жизни:
Adapter	    - Переходник с USB-C на HDMI
Bridge	    - Пульт, управляющий разными телевизорами через общий интерфейс
Composite	- Папки и файлы в файловой системе
Decorator	- Кофе с добавками (молоко, сахар, сливки)
Facade	    - Ресепшн в отеле, через который ты решаешь все вопросы
Flyweight	- Буквы в документе — хранятся один раз, но отображаются много раз
Proxy	    - Заместитель, действующий от имени другого (например, банковская карта — прокси к счёту)

3 Поведенческие (Behavioral)
Отвечают за взаимодействие и распределение обязанностей между объектами.
Основные:
Chain of Responsibility  - (Цепочка обязанностей)
Command         - (Команда)
Interpreter     - (Интерпретатор)
Iterator        - (Итератор)
Mediator        - (Посредник)
Memento         - (Хранитель)
Observer        - (Наблюдатель)
State           - (Состояние)
Strategy        - (Стратегия)
Template Method - (Шаблонный метод)
Visitor         - (Посетитель)
