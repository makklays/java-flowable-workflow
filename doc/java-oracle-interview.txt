Хотят услышать:

Коротко:

🔥 III. Multithreading & Concurrency (очень важный блок для Oracle)
9. Difference between synchronized, Lock, ReentrantLock, and StampedLock?

Хотят:
synchronized → блокировка монитором, no fairness
Lock → гибкость, tryLock(), interruptible
ReentrantLock → fairness, condition variables
StampedLock → read/write + optimistic read
