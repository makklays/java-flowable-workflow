Вариант 1: Incoming Webhook (простой)
Перейди в:
👉 https://api.slack.com/apps
Нажми “Create New App” → “From scratch”
Дай имя, выбери workspace
Перейди: “Incoming Webhooks” → Activate → Add New Webhook to Workspace
Выбери канал (например, #alerts)
Slack даст тебе URL вида:

-----
форматирование сообщения для text:
{
  "text": "*Жирный текст* _курсив_ `код`
<https://example.com|текст ссылки>
:rocket: :white_check_mark:"
}
Поддерживаемые элементы:
*жирный*
_курсив_
`код`
<url|описание> — кликабельные ссылки
> — цитаты
:emoji_name: — эмодзи

После перезапуска приложения метрики будут доступны по URL:
👉 http://localhost:8081/actuator/prometheus
Проверить можно так:
curl http://localhost:8081/actuator/prometheus | head -n 20

Что дальше?
Если хочешь подключить Grafana + Prometheus, тебе нужно:
Prometheus config (prometheus.yml)
scrape_configs:
  - job_name: 'spring-boot-app'
    metrics_path: '/actuator/prometheus'
    static_configs:
      - targets: ['host.docker.internal:8081']
Grafana
Подключи Prometheus как Data Source (http://localhost:9090).
Импортируй дашборд:
👉 https://grafana.com/grafana/dashboards/4701 — готовый шаблон для Spring Boot + Micrometer.
